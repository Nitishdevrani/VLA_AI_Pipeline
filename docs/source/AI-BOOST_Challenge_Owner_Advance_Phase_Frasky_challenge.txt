KPI and Evaluation Metrics
6
KPI 1 – Intent Recognition Accuracy: ≥ 90% correct identification of user intents and associated 
parameters (task, objects, location, constraints) from voice/text instructions, evaluated against 
ground-truth annotations for predefined tasks and actions.
KPI 2 – Task Planning and Execution Success: ≥ 85% successful mission completion, assessed by 
comparing generated ROS-compatible task sequences with reference plans and validating execution 
in simulation or a controlled ROS environment.
KPI 3 – Robustness to Language Variability: ≥ 85% task success across 3–5 semantically equivalent 
instruction variants per mission, evaluating consistency across different linguistic formulations.
KPI 4 – End-to-End Processing Latency (bonus): Average processing time from speech input to 
ROS-compatible mission generation within a 5–10-second target, measured across multiple test 
scenarios.
KPI 5 Task Completion Time (bonus): Overall time between user input and task completion.

=== page 10 ===
Frasky Digital Twin
10
•
Robot kinematic model (URDF): Definition of 
the robot’s links, joints, reference frames and joint limits, 
describing its mechanical structure and allowable 
motion.
•
Robot geometry (CAD meshes): CAD-derived 
3D meshes associated with the URDF links to reproduce 
the robot’s geometry and support visualization and 
collision checking.
•
Containerized robot control (Docker): 
Robot control modules and software dependencies 
packaged in a Docker container, providing a 
reproducible execution environment interfaced with the 
simulated robot.
